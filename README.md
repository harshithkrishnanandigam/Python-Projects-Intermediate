* 🧱 Object-oriented programming

## 🧠 Learning Approach

Each project is developed progressively:

```text
💡 Learn the concept
        ↓
⌨️ Build the project
        ↓
🐛 Debug and improve
        ↓
🚀 Add advanced features
        ↓
🔍 Review the code
        ↓
📖 Document the project
```

The goal is not just to complete projects, but to understand the concepts behind them and gradually develop the ability to build practical Python applications independently.
